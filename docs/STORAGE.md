# Память и хранилище (версия 5.7)

Настройки → **«Память и хранилище»**.

## Где хранятся данные
Браузер сам выбирает место: данные лежат **на этом устройстве внутри браузера** — `localStorage` (основные данные, память агента, сценарии, копии), IndexedDB (история калькулятора, чему научился агент) и кэш файлов (чтобы приложение работало без сети). Выбрать другое место (папку, карту памяти) браузер не позволяет; для переноса и страховки есть «Сохранить копию в файл» (экспорт JSON).

## Что показывает раздел
- Сколько занято данными Контура и по группам: основные данные · переписка и память агента · сценарии/привычки · резервные копии · блок-схемы · калькулятор · прочие настройки; отдельно — кэш приложения и «чужие» данные других ваших приложений на том же адресе (их не считаем в лимит и не трогаем).
- Сколько занято у всего сайта и сколько доступно браузеру (по оценке браузера) и включена ли **защита от автоочистки браузером**.

## Лимит объёма
- Переключатель **«Ограничить объём данных Контура»** + ползунок 5–500 МБ. Выключено — **без ограничений** (по умолчанию).
- Когда лимит превышен, Контур освобождает место сам, по лестнице от безобидного: старые резервные копии (до 3) → старая переписка с агентом (до 150 сообщений) → история калькулятора (до 300 записей) → копии (до 1) → переписка (до 50) → история калькулятора (до 30) → переписка (до 10) → все копии. Останавливается, когда занято ≤ 90% лимита.
- **Никогда не удаляются**: встречи, задачи, контакты, заметки, цели, сценарии, схемы, привычки. Если они сами больше лимита, видно предупреждение — увеличьте лимит.
- Проверка: при запуске, каждые 2 минуты, при сворачивании приложения и сразу после смены лимита.
- **Страховка от переполнения браузера:** если браузер отказал в записи (квота), Контур освобождает копии/переписку и повторяет запись один раз.

## Кнопки
| Кнопка | Что делает |
|---|---|
| Освободить место сейчас | запускает автоочистку (с лимитом — до лимита; без лимита — убирает всё второстепенное, что можно) |
| Защитить данные от очистки браузером | просит браузер не удалять данные при нехватке места (на iPhone работает у приложения, установленного на экран «Домой») |
| Пересчитать | заново измеряет занятое место и кэш |
| Сохранить копию в файл | экспорт всех данных |
| История чата / Резервные копии / История калькулятора | очистка вручную, **два нажатия** (без системных окон подтверждения) |
| Сбросить кэш приложения | удаляет файлы для работы без сети и отключает сервис-воркер, затем перезагружает приложение; **ваши данные остаются**; нужен интернет для повторной загрузки |

## Устройство (`js/orbit/storage.js`)
`O.storage`: `measure()`, `enforce({limit, quiet})`, `emergency(key)`, `clearCache()`, `persist()`, `refresh()`. Для усечения чата агент предоставляет `Orbit.assistant.trimHistory(n)` и `clearChat()`. Тесты — группа «Память».

## Ограничения
- Объём IndexedDB и кэша считается по содержимому (браузеры не дают точных цифр); «весь сайт» — оценка браузера.
- Голосовые заметки (аудио) хранятся в основных данных и самым крупным «пожирателем» памяти быть могут — раздел показывает их размер отдельной строкой; автоматически они не удаляются.
- Для переезда в базу данных (версия 5.8) этот модуль остаётся локальным слоем: см. `docs/DB-MIGRATION-5.8.md`.
