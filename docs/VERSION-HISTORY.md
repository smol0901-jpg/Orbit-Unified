# История версий Контура (append-only)

> **Для агентов, разработчиков и CI.**  
> Этот файл — **единственный канонический журнал** всех релизов и правок.  
> Его **нельзя перезаписывать целиком**. Новая версия **только дописывается сверху** (после блока «Как вести файл»).

---

## Как вести этот файл (обязательно)

1. **Не стирать и не переписывать** уже существующие разделы `## X.Y.Z`.
2. Каждая новая версия добавляется **сразу под** этим блоком инструкций, **выше** предыдущих версий (новые сверху).
3. Формат заголовка строго:
   ```
   ## X.Y.Z — краткий заголовок (YYYY-MM-DD)
   ```
4. Внутри раздела использовать подзаголовки:
   - `### Исправлено` — баги
   - `### Добавлено` — фичи
   - `### Изменено` — поведение / API
   - `### Очередь` — что сознательно отложено
5. Указывать **файлы**, которые трогали (пути относительно корня репозитория).
6. Синхронизировать с:
   - `version.json` → поле `version` и `notes`
   - `js/app.js` → `const APP_VERSION = 'X.Y.Z'`
   - `sw.js` → `const V = 'contour-vX.Y.Z'`
   - `CHANGELOG.md` (краткая человекочитаемая выжимка; детали — здесь)
7. Self-check тесты «Версия едина» и «Сервис-воркер: версия = APP_VERSION» должны проходить после bump.
8. Рекомендуемый скрипт bump (идея для CI):
   ```bash
   # npm run bump 5.8.9
   # правит version.json, APP_VERSION, CACHE в sw.js одной операцией
   ```

## 5.8.9 — очередь тест-прогонов + история версий (2026-10-21)

### Исправлено
- **Версия:** изначально линейка 5.8.x велась как 5.8.8; в промежуточных сборках ошибочно стояли 5.8.5/5.8.6. Канон: **5.8.9**. Синхронизированы `version.json`, `APP_VERSION`, `sw.js` (`contour-v5.8.9`).
- **Даты в чате:** fallback-обработчик «дней между A и B» / «сколько дней до …» в `assistant.js`, если inline-skill не сработал (устранение тайм-аутов self-check).
- **undo / отмена:** всегда быстрый ответ («Нечего отменять.» / «Отменено.»), без зависания.
- **Diary overflow:** `min-width:0`, `max-width:100%` для секции журнала / mood-row (320/390 px без горизонтального скролла).
- **Заглушка «Облако»:** короткий ответ по спеке self-check («в разработке, версия 5.8»).
- **Сценарии ✎:** кнопка редактирования всегда активна — graph → FlowForge, иначе локальный редактор; подсказка если модуль не загружен.
- **Пустой chip «ОСВОБОЖУСЬ»:** убраны пустые элементы в ряду chips транспорта.
- **Заметка агента → Заметки:** `addNote` гарантированно пишет в `state.notes` и вызывает `save/render`.
- **Быстрые команды агента:** дедуп плиток (уникальные label/cmd).
- **Цвет типов событий:** единый token (встреча / блок) в ленте и плане дня.
