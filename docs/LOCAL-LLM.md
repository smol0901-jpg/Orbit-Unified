# Локальная нейросеть для Контура (план, без интеграции)

> **Код приложения пока не меняем** под модель. Этот файл — инструкция, что скачать и куда положить, когда будете готовы.

## Стоит ли?

**Да, как опциональное улучшение**, не как обязательная зависимость:

| Плюсы | Минусы |
|--------|--------|
| Работает офлайн, без API-ключей | 200–800 МБ на устройство |
| Приватность (данные не уходят) | На слабых iPhone WebGPU может не хватить памяти |
| Fallback, когда лимиты LLM7/облака кончились | Качество слабее GPT-класса |

Для PWA на телефоне/планшете/ПК оптимальны **крошечные** модели (≤ 500 МБ).

## Что скачать (рекомендация)

### Вариант A — WebLLM (MLC, проще для браузера)

- Runtime: https://github.com/mlc-ai/web-llm  
- Маленькие модели: **SmolLM2-360M**, **Qwen2.5-0.5B**, **Qwen3-0.6B** (q4) — ~210–350 МБ  
- Демо офлайн-чата: https://github.com/ebenezerdon/webllm-offline-ai  

### Вариант B — wllama (llama.cpp WASM, любые GGUF)

- https://github.com/ngxson/wllama  
- Любой GGUF с Hugging Face, если влезает в память.

### Вариант C — toolkit

- https://github.com/LocalMode-AI/LocalMode — WebLLM + wllama + Transformers.js.

**Практичный выбор для Contour:** WebLLM + SmolLM2-360M / Qwen2.5-0.5B — short-reply и fallback при исчерпании облачных лимитов.

## Куда положить в репозитории

```
Orbit-Unified-main/
  vendor/
    local-llm/
      README.md          ← что за модель, лицензия, размер
```

Веса >50 МБ лучше не коммитить в git: CDN / GitHub Release, при первом запуске — Cache Storage / OPFS (как у WebLLM).

## Когда подключать код

1. Скачали runtime и/или модель.  
2. Положили в `vendor/local-llm/` (или дали URL CDN).  
3. Написали: «модель залита».  
4. Тогда добавим провайдер `local` в `js/orbit/llm.js` и переключение при `orbit-llm-limit`.

До этого шага **ничего в коде под модель не ломаем**.
