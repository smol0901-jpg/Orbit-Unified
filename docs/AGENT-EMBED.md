# Агент: формат встраиваемых модулей

Новые возможности, которые **агент открывает**, должны появляться **карточкой в ленте сообщений** (как график и помидор), а не отдельной вкладкой.

## Правило
1. Ответ агента = `R(текст, { cards: [html], buttons: [...] })`.
2. Карточка интерактивная: `data-*` + делегирование кликов (см. `js/orbit/inline.js`: `pomoCard`, `settingsCard`).
3. Опционально «Закрепить» — sticky-панель внутри `.o-chat`.
4. **Исключения** (уже так): калькулятор и FlowForge — dock/iframe в чате или полный редактор по явной кнопке.

## Настройки из агента
- «настройки» / «оформление» / «тема» → карточка стиля (тема, шрифт, масштаб, скругление, стекло, анимации, контраст).
- «настройки агента» → подсказки, голос, помидор, офлайн.
- «Все настройки» → полный экран настроек.

Не перезаписывать этот файл при правках — только дополнять примеры.
