> **Правило ведения:** файл **только дополняется**. Не стирать и не перезаписывать старые разделы.
> Новая функция / версия → добавить блок в конец (или в таблицу версий) с датой и номером сборки.
> После **каждой** сборки прогонять раздел «Регресс после сборки».

---

## 0. Как проверять после сборки

1. Установить/залить сборку, **сбросить кэш** (SW: Application → Unregister / hard reload).
2. Открыть «Ещё → О приложении»: версия = `version.json` = `APP_VERSION` = `sw.js` cache-name.
3. Пройти **A. Агент — команды** (по 1 фразе из каждой группы).
4. Пройти **B. Вкладки агента** (все 7).
5. Пройти **C. Основные вкладки приложения**.
6. Отметить в журнале внизу: дата, версия, ✅/❌ по блокам, краткий комментарий.
7. Если ❌ — не поднимать версию в релиз, пока блок не зелёный.

**Критерий «на месте»:** команда даёт осмысленный ответ **без** «Что-то пошло не так» и без пустого экрана.

## E. Паттерн встраивания (для новых фич)

См. также `docs/AGENT-EMBED.md`.

1. Новое из агента → **карточка в ленте** (`R(text, { cards: [html] })`).
2. Исключения: калькулятор (dock/iframe), полный FlowForge (tab по кнопке).
3. Опционально «Закрепить» → sticky в `.o-chat`.
4. После добавления — **дописать** строку в таблицы выше и строку в журнал версий.
