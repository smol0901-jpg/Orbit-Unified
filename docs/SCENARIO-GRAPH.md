# Сценарии-графы (версия 5.4)

Сценарий агента — **блок-схема**, которую Кон исполняет. Готовая схема из FlowForge превращается в сценарий, а всё, что собрали блоки, выводится в чат **одним отчётом**.

## Как пользоваться
- **Кнопка:** плитка «Отчёт дня» на экране «Сегодня» (или фраза «отчёт дня», «сводка», «мой отчёт»).
- **Сценарии** (агент → «Сценарии»): ▶ запустить, ✎ открыть в блок-схеме (FlowForge), ✕ удалить; «🧩 Отчёт дня» — шаблон, который можно добавить ещё раз.
- **Из своей схемы:** «📥 Из блок-схемы (FlowForge)…» → выбрать проект → он становится сценарием (запуск вручную кнопкой ▶; выбор фразы или времени для сценария-схемы появится в следующих версиях).

## Первая схема — «Отчёт дня»
Начало → Сегодня и встречи → Задачи → Планы → Проверить напоминания → Маршруты (ближайший автобус домой) → Правки → Показать отчёт → Конец.
Результат: одно сообщение со сводкой «⚠️ Внимание: просрочено задач/напоминаний» и карточкой на каждый раздел.

## Блоки
| Блок | Что делает |
|---|---|
| Начало / Конец | границы схемы |
| Сообщение | текст в отчёте (`{{переменная}}` пока не заполняется — задел) |
| **Команда агента** | любая фраза из каталога навыков («что взять завтра», «позвони маме», «добавь задачу …»); ответ агента попадает в отчёт |
| Сегодня · Задачи · Планы · Напоминания · Правки | встроенные блоки-данные (сразу структурированные разделы отчёта) |
| Показать отчёт | вывести накопленное сейчас (в конце сценария выводится автоматически) |
| Условие Да/Нет | ромб: условие по тексту («Есть открытые задачи?», «Сегодня выходной?», «После 18:00?») либо **вопрос пользователю** кнопками «Да/Нет» |

## Как схема FlowForge превращается в сценарий
- Терминатор без входящих → «Начало»; «Конец/Готово/Стоп» → «Конец».
- Блок-процесс: если Кон понимает текст как команду → «Команда агента»; ключевые слова («задачи», «напоминания», «правки», «планы», «сегодня») → блок-данные; иначе — «Сообщение».
- Ромб: связи подписываются **«Да» / «Нет»** (также yes/no, +/−). Условие угадывается из текста; если не понято — Кон спросит.
- Узлы, созданные вручную, можно подсказать точнее полем `ag` (формат — `js/orbit/flow.js`).

## Устройство (`js/orbit/flow.js`)
- Формат: `{ nodes:[{id,type,text,ag:{b,…}}], edges:[{from,to,label}] }` — совместим с FlowForge (`toScheme`/`fromScheme`).
- Исполнитель идёт по связям (стек), ветвит по ромбам, ограничения: 300 шагов, 25 заходов в один блок (защита от бесконечных циклов), ошибка блока не роняет сценарий.
- Команды выполняются «тихо» (`Orbit.assistant.quiet`), вопросы Да/Нет — через диалоговый фокус (`askYesNo`, работает и голосом).
- Открытие в FlowForge — через `postMessage` (тот же origin).

## Режим «Сценарий агента» в FlowForge (5.5)
Внутри Контура в шапке FlowForge появилась кнопка **🤖**. Она открывает панель:
- **Название и запуск:** вручную / фразой в чате / по времени (по будням или ежедневно).
- **▶ Запустить** — схема исполняется прямо из редактора, **текущий блок подсвечивается**; отчёт появляется в чате агента (кнопка «📋 Отчёт» ведёт туда). Если в схеме есть вопрос «Да/Нет», Кон сам откроет чат и спросит.
- **💾 В агента** — схема сохраняется как сценарий (повторное сохранение обновляет тот же сценарий).
- **Блоки** (тап — блок добавляется и **соединяется с выбранным**; после ромба связи сами получают подписи «Да» и «Нет») и **Команды агента** — весь каталог навыков: тап ставит блок-команду с примером фразы, текст можно править.
- У выбранного блока в панели свойств появляется раздел **«Блок агента»**: тип блока, заголовок раздела отчёта, а у ромба — условие (по тексту / вопрос пользователю / будни-выходные / есть задачи / просрочено / напоминания / встречи / до-после времени).
- ✎ у сценария-схемы в «Сценариях» открывает его здесь же, с блоками, условиями и настройкой запуска.
Блоки агента хранятся в самой схеме (поле `ag` у блока, `agent` у схемы), поэтому сохраняются в проекте, экспорте JSON, копировании и отмене действий.

## Ограничения сейчас
- Звонок нельзя набрать автоматически (iOS): блок «позвони» покажет карточку звонка в отчёте.
- Сценарий по времени работает только при открытом приложении.
- Отчёт не сохраняется при перезагрузке страницы.
