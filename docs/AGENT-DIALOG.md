# Диалог Кона: фокус между сообщениями

Кон помнит **незаконченную команду** и принимает уточнение следующим сообщением (или через несколько). Работает и для голоса и для кнопок («Отмена», «Подтверждаю» — это обычные сообщения).

## Как это выглядит
- «позвонить» → «Кому позвонить?» → «Василию» → карточка звонка (так же «написать»).
- «напомни позвонить маме» → «Когда напомнить?» → «завтра в 9:00» → напоминание. Если пусто («напомни») → «О чём напомнить?» → потом «когда».
- «запиши в заметке» → «Что записать?» → текст → «Ещё что-то записать?» (любое сообщение дописывается в заметку; «всё»/«хватит» — дальше) → «Напомнить об этом?» (время, «нет» или «да» → «когда?») → «Подтверждаете?» → «подтверждаю» → заметка и напоминание сохранены, есть «Отменить».
- «добавь задачу» → «Какая задача?» → название → задача создана.
- В любой момент «отмена» / «стоп» выходит из диалога. Фокус живёт 10 минут.

## Как устроено (js/orbit/assistant.js, блок «ФОКУС ДИАЛОГА»)
- `focusSet(kind, data, fn)` запоминает вопрос; `fn(text, n, data)` получает следующее сообщение и возвращает: ответ (сообщение принято), `null` (не по теме — фокус сбрасывается, сообщение обрабатывается как обычная команда).
- `focusStep(text)` вызывается **первым** в `A.process` — раньше разговорной математики и остальных правил.
- `looksLikeCommand(text)` отличает уточнение от новой команды (в коротких ответах вроде «Василию»). В шаге «записать текст» любое сообщение — содержимое заметки (чтобы можно было записать «позвонить Ивану»); выйти можно словом «отмена».
- Время: `whenToDate` / `tIn` понимают «завтра в 9:00», «в 9 вечера», «через час»; голое «в 9» теперь = 09:00 (раньше молча ставилось 08:00).

## Как добавить свой диалог
1. В правиле: `focusSet('мой-вид', { …данные… }, (t, n, d) => { … });` и вернуть вопрос `R('…', { buttons: [cancelBtn()] })`.
2. В обработчике: когда всё собрано — `focusClear()` и выполнить действие (удобно: `understand('<команда целиком>')`, чтобы использовать готовые правила).
3. Тест в группе «Диалог» в `tests/suite.js`.

## Что пока не умеет
- Перекрёстные вопросы («а завтра?» без контекста), память темы дольше 10 минут, правка уже введённых строк заметки на шаге подтверждения (можно «добавить ещё» или «отмена»).
- Полноценный рассуждающий диалог — для нейросети (версия 6.x+).
