# Журнал изменений

## 5.2.0 — калькулятор и схемы прямо в чате, тесты на все навыки
**Калькулятор в чате.** «калькулятор» открывает в чате закреплённую панель с настоящим CIFRA (счёт, конвертер, финансы, даты, график, доска, учёт) — вкладка не переключается, состояние не сбрасывается при новых сообщениях, результаты из чата попадают в панель. Текстовые навыки: проценты, скидки, наценка, НДС, конвертер единиц, кредит, вклад, даты, системы счисления, уравнения, статистика, «ответ*2», история вычислений.

**Схемы в чате.** Схема собирается сообщениями с живым превью (ветки Да/Нет, правка, отмена, шаблоны). Редактор FlowForge открывается только по команде, после него чат не предлагает собирать заново и не принимает обычные фразы за шаги. Режим схемы сам выключается через 15 минут.

**Навыки агента.** Тесты на все 43 навыка каталога и их примеры. Исправлено: `sqrt(16)` уходил в «обмен»; `sin(30)` не понимался; «сумка на завтра» не понималась; «нарисуй y=x^2» давал кривой заголовок; в номер маршрута попадало время («Метро 08»); цепочка `A -> B -> C` давала 2 блока; «добавь задачу релиз 2.4» теряла слово «релиз»; категория «Инструменты» не показывалась в панели «Навыки»; опечатка «Удалить встречуи дня».

**CIFRA.** Факториал `5!` не работал (токенизатор бросал ошибку на «!»). Добавлено управление извне (`postMessage {type:'orbit-calc', tab, expr}`).

## 5.1.0 — рабочее пространство для IT, менеджеров, директоров, самозанятых и ИП
**Ребрендинг.** Продукт больше не школьный: встречи вместо уроков, блоки вместо кружков, задачи вместо домашки, отпуск вместо каникул, «на работу» вместо «в школу», журнал вместо дневника, должность/компания в профиле. Переписаны демо-данные, словарь тем и сокращений, подсказки и ответы ассистента, формы, шаблоны Excel/Word/JSON, промпт для нейросети, manifest. Ассистент понимает и новые, и старые формулировки.

**Исправлено.**
- Настройки не открывались (пропал список цветов акцента) — исправлено; выбранный акцент теперь действительно применяется.
- Калькулятор и графики в чате не работали (движок CIFRA не попадал в `window`).
- Офлайн-режим: три сервис-воркера (Контур, CIFRA, FlowForge) стирали кэши друг друга; теперь один воркер на проект, старые отдельные воркеры снимаются, библиотеки dagre/jsPDF кэшируются, старые кэши чистятся по префиксу, iframe-страницы больше не затирают запись главной.
- Битая ссылка `?go=…` давала пустой экран.
- Повреждение основного ключа данных приводило к потере данных: теперь восстановление из резервной копии; резерв хранит предыдущую версию, а не копию текущей; пустые записи в массивах отбрасываются.
- Время `25:61` принималось как корректное.
- Чат «зависал» навсегда после любого сбоя отрисовки.
- «открой настройки» только отвечало, но не открывало раздел.
- Дубли карточек стилей в приветствии; одинаковые id градиентов логотипов.
- Горизонтальная прокрутка на экранах 320–390 px (быстрые действия, канбан).
- Версия в «О приложении» (4.4.2) не совпадала с релизом.

**Добавлено.** Набор из 114 тестов (`/tests/` в браузере и `tests/run.py`).
