# Журнал изменений

## 5.8.6 — LLM7 fast, версия, CIFRA в iframe
**Исправлено.** LLM7: модель по умолчанию `fast`, без `Bearer unused` (больше нет 401 на пробном запросе).  
**Исправлено.** `APP_VERSION` в `js/app.js` — в «О приложении» больше не залипает 5.8.4.  
**Исправлено.** CIFRA Pro в iframe: режим `html.embedded`, высота от iframe а не 100dvh — кнопки не обрезаются нижней навигацией Контура.


## 5.8.5 — LLM7 без ключа, AMOLED, агент
**Исправлено.** Диагностика LLM (`llmTest`) больше не требует API Key для бесплатных провайдеров (LLM7.io и аналоги с `noKey`/`free`).  
**Исправлено.** AMOLED-тема: чистый чёрный фон (#000), убраны glass-свечения, карточки и шапка почти чёрные — разница с обычной тёмной темой заметна.  
**Улучшено.** Агент: быстрые кнопки (Что дальше / Когда выходить / Добавь задачу / Помощь), интент «помощь / что умеешь / нейросеть / llm7», понятнее ответы при непонимании.  
**Изменено.** Заглушки облака окончательно на «ближе к версии 10.0 (в 5.x не успеваем)». Текст мастера нейросети: ключ для LLM7 можно оставить пустым.

## 5.8.4 — CSP, LLM7 бесплатно, заглушки облака → ~10.0
**Добавлено.** LLM7.io как бесплатный провайдер без ключа (`js/orbit/llm.js`). Content-Security-Policy в `index.html` (api.llm7.io и др.).  
**Изменено.** Заглушки облака (CLOUD_SOON, панель «Облако») перенесены с «версия 5.8» на «ближе к 10.0 (в 5.x не успеваем)». Документы `CLOUD-STUBS.md` и `ROADMAP-5.8.md` обновлены.  
**Исправлено.** Единообразие версий (version.json, APP_VERSION, кэш SW).
