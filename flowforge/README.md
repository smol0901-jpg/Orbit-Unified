# ⚡ FlowForge Studio

Онлайн-конструктор блок-схем: телефон, планшет, ПК · PWA (офлайн) · PNG / SVG / PDF · JSON-шаблоны · генерация схем через ИИ.
Статический проект без сборки — работает на **GitHub Pages**.

## Публикация на GitHub Pages
1. Залейте содержимое папки в репозиторий (корень, ветка `main`).
2. **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
3. Через минуту сайт откроется на `https://<логин>.github.io/<репозиторий>/` — все пути относительные.

## Возможности
- 7 типов блоков: старт/конец, процесс, условие, ввод/вывод, данные, подпроцесс, заметка
- Управление мышью, пальцем и пером (Pointer Events): щипок — зум, перетаскивание — сдвиг, двойной тап — правка текста
- Связи: тянуть кружок у выбранного блока; в пустое место — создаётся новый блок; режим «🔗» для тапов
- Подписи связей (Да / Нет), цвет блока, смена типа, «Развернуть» связь
- Мультивыбор (Shift / рамка), копирование/вставка/дубликат, стрелки — сдвиг
- Undo/Redo (100 шагов), автосохранение, привязка к сетке
- Добавление блока по тапу в палитре — автоматически соединяется с выбранным
- **Мини-карта** в углу: вся схема целиком, рамка текущего вида, тап или перетаскивание — переход (включается кнопкой 🗺)
- **Линии связей**: плавные, угловые (A* обходит блоки, не пересекая их) и прямые; тип можно задать глобально (кнопка в шапке) или для каждой связи отдельно
- **Стили линий**: сплошная, пунктир, точки, штрих-точка; стрелка →, ↔ или без; толщина и цвет
- **Группы**: выделить несколько блоков → ▣ (Ctrl+G) — рамка с названием и цветом; тянется за заголовок вместе с блоками; Ctrl+Shift+G — разгруппировать

## Установка как приложение (PWA)
Сначала один раз откройте сайт онлайн, чтобы он закэшировался. Дальше работает и без интернета.

**Android (Chrome):** меню ⋮ → «Установить приложение» → «Установить».
**iPhone и iPad (Safari):** кнопка «Поделиться» → «На экран Домой» → «Добавить». Именно Safari.
**Windows, Mac, Linux (Chrome, Edge):** значок установки справа в адресной строке → «Установить». Если значка нет: меню ⋮ → «Установить FlowForge» (Edge: … → Приложения → «Установить этот сайт как приложение»).
**Safari на Mac (macOS 14+):** Файл → «Добавить в Dock». Firefox на компьютере установку сайтов не поддерживает.

Обновления подтягиваются сами: новая версия загружается при запуске с интернетом и применяется при следующем открытии. Удалить: как обычное приложение. Схемы лежат в браузере или приложении, для переноса между устройствами сохраните JSON. Эта же инструкция есть в приложении: меню → «Ещё».

## Формат JSON (v2.8)
```json
{"format":"flowforge","version":"2.8",
 "nodes":[{"id":"n1","type":"terminal","text":"Начало"}],
 "edges":[{"from":"n1","to":"n2","label":"Да","route":"ortho","dash":"dashed","arrow":"both","color":"#f38ba8","width":3,"pts":[[300,200]]}],
 "groups":[{"id":"g1","title":"Этап 1","color":"#89b4fa","nodes":["n2","n3"]}]}
```
Свои фигуры: верхнее поле `shapes` (описание рисованных и картиночных фигур, подставляется автоматически). Новые типы блоков: delay, display, card, tape, merge, extract, sort, collate, or, sumjn, offpage, loopstart, loopend, manualop, internal, directdata, annot, ellipse, triangle, rtriangle, pentagon, octagon, star, cross, chevron, arrowr, arrowl, arrowu, arrowd, trapezoid, bevel, snip, cloud, heart, bolt, callout, bubble, banner, folder, person, shield, multidoc, server, clock, flag. Чек-лист: `ck:[{"t":"пункт","d":false}]`, отслеживание блока: `done:false`. Камера: `camera.rot` (поворот листа, радианы). Блок: `bd` (контур: thin, thick, dashed, dotted, none), `fs` (размер текста), `sw`/`sh` (свой размер), `lock`. Типы: terminal, process, decision, io, data, sub, note, doc, prep, conn, manual.
`pts` — изломы линии `[[x,y],...]`. `route`: curve | ortho | line · `dash`: solid | dashed | dotted | dashdot · `arrow`: end | both | none. Файлы старого формата открываются.

## Публикация новой версии
Адрес приложения для QR-кода: `LINKS.app` в `js/app.js`. При выпуске новой версии меняйте `VER` в `js/app.js` и номер `?v=` в `index.html` и `sw.js`: так браузеры и кнопка «Обновить» подтянут свежие файлы.
