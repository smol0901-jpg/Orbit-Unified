# Контур — рабочее пространство

**Для IT-специалистов, менеджеров, директоров, самозанятых и ИП.** Офлайн-PWA: день, маршруты, задачи, калькулятор, схемы и ассистент с памятью. Данные хранятся только на вашем устройстве.

## Модули

| Модуль | Назначение |
|--------|------------|
| **Сегодня** | Дашборд дня: ближайшая встреча, когда выходить, открытые задачи |
| **Расписание** | Встречи, личные блоки, события; отпуск и выходные |
| **Маршруты** | Дом ↔ работа: метро, автобус, пересадки, расчёт времени выхода |
| **Ассистент (Кон)** | Команды текстом и голосом, память 300 сообщений; калькулятор и схемы работают прямо в чате |
| **Калькулятор** | CIFRA Pro: выражения, конвертер, финансы, даты, графики, доска, учёт — отдельной вкладкой и прямо в чате |
| **Схемы** | FlowForge Studio: блок-схемы, экспорт PNG/SVG/PDF |
| **Задачи · Журнал · Заметки · Доска** | Дела со сроками, итоги дня, заметки, канбан |
| **Контакты · Обмен** | Команда и клиенты, SOS; QR-обмен, файлы `.contour`, Excel/Word-шаблоны |

## Что можно сказать ассистенту

- `добавь встречу Планёрка пн вт ср 9:30-10:00`
- `добавь задачу Релиз 2.4 до пятницы` · `мои задачи` · `сделал задачу Релиз`
- `когда выходить на работу` · `добавь маршрут до работы метро 08:30`
- `посчитай 12*8` · `график sin(x)` · `создай схему`
- `перенеси демо на среду` · `удали встречу Демо пн` · `отмени`
- `журнал созвон прошёл хорошо` · `что было вчера`

Формулировки прежних версий тоже понимаются как синонимы.

## Калькулятор и схемы прямо в чате

- `калькулятор` — в чате открывается панель с настоящим CIFRA (все разделы), вкладка не переключается; `калькулятор конвертер|финансы|даты|график` открывает нужный раздел внутри панели.
- Текстом, без панели: `15% от 2000` · `скидка 20% на 3500` · `ндс 20% на 1200` · `выдели ндс из 1200` · `5 км в мили` · `100 °F в °C` · `кредит 1000000 на 5 лет под 12%` · `вклад 500000 под 8% на 3 года` · `сколько дней до 31.12` · `через 45 дней` · `255 в hex` · `реши x^2-5x+6=0` · `среднее 3 5 7` · `5!` · `ответ*2` · `история вычислений`.
- `создай схему` — схема собирается в чате: пишите шаги сообщениями или цепочкой `Старт -> Проверка -> Конец`, условия `Оплата прошла? да: Выдать; нет: Вернуть`. Под сообщением живое превью. Правка: `добавь шаг …`, `убери шаг …`, `назови схему …`, `отмени шаг`. Редактор открывается только по команде `открой схему в редакторе`.

## Оформление

Контур · Пульс · Вектор · Сланец, тёмная/светлая/AMOLED тема, свой цвет акцента (Настройки → Оформление).

## Запуск

```bash
npx serve .          # или любой статический сервер; не через file://
```

Публикация: GitHub Pages / Netlify — достаточно загрузить содержимое папки. Приложение ставится на телефон как PWA и работает без сети.

## Самопроверка (240+ тестов)

- в браузере: откройте `/tests/` и нажмите «Запустить все тесты» (данные сайта временно очищаются и возвращаются; лучше запускать на localhost);
- из консоли: `pip install playwright && playwright install chromium && python3 tests/run.py`.

Что проверяется: запуск без ошибок, все разделы, единый рабочий словарь без устаревших терминов, встречи/задачи/маршруты, ассистент, калькулятор и схемы, импорт/экспорт, повреждённые данные, XSS, офлайн-режим, иконки и ярлыки PWA, вёрстка на 320–1280 px.
